# Сценарии HGT

Точки входа и порядок — в [HGT README](../README.md). `submit_H1_*` и `submit_H2_*` отправляют задания Slurm; `H1_*.sbatch`/`H2_*.sbatch` — исполняемые стадии, `prepare_*` и `fetch_*` готовят данные, `collect_*`, `h2_*review*` и `h2_*compare*` проверяют и сводят их. Не запускайте всё по алфавиту: многие файлы — внутренние шаги массивов, а `READY_ONLY` создаёт только промежуточный разбор.
