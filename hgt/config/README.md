# Зафиксированные входы HGT

`H1/` хранит снимок источников, соответствия локусов, отбор носителей и SHA-256. `H2/` хранит ортологические решения, состав панелей, модели, лимиты и входные манифесты. `sources/` — общие литературные и программные источники.

Локальные Slurm job IDs, accounting и списки переноса являются операционными квитанциями, а не конфигурацией: они исключены из Git и находятся в `results/slurm/` при новом запуске. Файлы `*.sha256` проверяйте из корня HGT; они привязаны к версии снимка.
