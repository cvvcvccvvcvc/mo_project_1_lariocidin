# HGT-проверка лариоцидиноподобных BGC

Эта линия использует отдельный снимок входов, не текущий рабочий каталог diversity. [План](plan.md) фиксирует статус и следующий шаг, [находки](FINDINGS.md) — только выполненные выводы. H1-связь локусов с геномами и часть H2-деревьев готовы; Actino138 host fit продолжается, формальная проверка HGT ещё не выполнена.

## Входы и окружение

- `inputs/` — крупные неизменные снимки вне Git. Текущие SHA-256 — в `config/H1/` и `config/H2/`, исходные manifests — в `provenance/historical/`; без этих снимков один clone не повторяет исторический анализ.
- `config/` — зафиксированные выборки, решения по ортологии, модели и ресурсы; `results/` — таблицы, деревья и checkpoints; `scripts/` — стадии Slurm.
- Для расчёта задайте `HGT_ROOT` как абсолютный путь к **этому** каталогу, `HGT_GENOME_ROOT` как путь к проверенным H1-геномам и `HGT_BIN` как каталог бинарников личного HGT-окружения. Дополнительные версии указаны в `config/H2/H2_tools_explicit.txt`. Не помещайте личные пути или адреса кластера в Git.

## Повторение на Slurm

1. Получите H1/H2 snapshots по манифестам и сверьте SHA-256. Проверьте входную таблицу, окружение, свободное место и текущие лимиты кластера; тяжёлые команды запускайте только заданиями Slurm.
2. H1: `scripts/steps/prepare_h1.py` → `scripts/run_h1_homology.sh` → `scripts/steps/fetch_h1.py` → `scripts/submit_H1_array.sh` и `scripts/submit_H1_supplement.sh` → `scripts/steps/collect_h1.py`. Дополнения и 4BL1 имеют свои зафиксированные входы и задания; не включайте их молча в старый снимок.
3. H2: `scripts/steps/prepare_h2.py` → `scripts/submit_H2_native.sh` → поиск маркеров → `scripts/submit_H2_collect.sh <текущий-marker-job-id>` → подготовка деревьев → `scripts/submit_H2_hosts.sh` и, при наличии входов, `scripts/submit_H2_actino_trees.sh`. Отдельные `.sbatch` задают ресурсы; списки задач в `results/H2/*/tree_jobs.tsv` не меняйте во время array run.
4. Сравнивайте только законченные основные ML-деревья с проверенными leaf IDs и marker QC. `HGT_READY_ONLY=1` у `H2_compare_plot.sbatch` даёт промежуточный разбор без незавершённого Actino138; он не закрывает H2. Таблицы и ограничения — в [находках](FINDINGS.md).

Скрипты с префиксами `H1_` и `H2_` реализуют названные стадии; `submit_*` отправляют связанные задания, остальные Python-файлы готовят входы, проверяют ортологию или сводят результат. Запускать их по алфавиту не требуется. Запрещено считать неопределённые BGC отрицательным контролем, а незавершённый fit — завершённым результатом.
