# Проверка гипотез HGT

HGT анализирует отдельный зафиксированный снимок лариоцидиноподобных BGC: связывает опубликованные локусы с геномами (H1), сравнивает деревья компонентов и хозяев (H2), затем оценивает гипотезы переноса (H3). Это исследование отдельных генов, а не доказательство переноса целого кластера.

**Сейчас:** H1 и описательное сопоставление H2 завершены; H3 выполнил адресные проверки и ограниченный общий экран gCF/AU. Текущие данные не устанавливают событие переноса. Числа и граница вывода — в [результатах](docs/results.md).

Для повторения нужны Linux, Slurm, отдельно полученные замороженные входы и окружение. Начните с [карты данных и контрольных сумм](docs/data.md), затем следуйте [методу и точкам входа](docs/method.md). Общие правила подключения к кластеру без личных адресов и ключей описаны в [README проекта](../README.md). Крупные входы и новые расчёты не коммитятся; зафиксированные небольшие таблицы и деревья позволяют проверить уже заявленные выводы.
