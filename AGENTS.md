# Работа в репозитории лариоцидина

- Корень Git и область проекта — этот каталог. Читайте только документ, владеющий задачей: общая научная рамка — `docs/research.md`; поиск BGC — `diversity/docs/method.md`, данные — `diversity/docs/data.md`, выводы — `diversity/docs/results.md`; HGT — `hgt/plan.md` и `hgt/FINDINGS.md`.
- Код, фиксированные выборки и JSON-протоколы являются источником точных команд, путей и порогов. Исторические manifests описывают прежний снимок; не исправляйте их под текущую структуру.
- Для анализа сохраняйте исходный accession/version, URL, SHA-256, версию инструментов, commit и параметры запуска. Не называйте предсказанный BGC подтверждённым продуктом, а несогласие деревьев — доказанным HGT.
- Не добавляйте в Git геномы, архивы метаданных, окружения, логи, личные пути, адрес кластера и ключи. Большие входы сверяйте по манифестам; приватное подключение остаётся вне репозитория.
- Делайте атомарный коммит после каждого законченного изменения: одна причина и проверяемый результат на коммит. Не объединяйте реорганизацию, изменение научных критериев и новые результаты. Перед коммитом выполните проверку затронутого маршрута и проверьте `git diff --check`; после серии изменений оставьте чистое дерево.
