# S5: зафиксированный протокол ограниченного HGT-разбора

Дата фиксации: 11.09.2026, до построения новых host/BGC-деревьев и топологических тестов.

## Вопрос и единица анализа

Проверяется один ранее выбранный случай: сходство A–D-локуса *Photorhabdus asymbiotica* DSM 15149 с локусами Burkholderiales среди 14 опубликованных Pseudomonadota BGC. Единица наблюдения — один ген BGC в одной сборке; пять сцепленных генов одного локуса не считаются независимыми событиями.

Основная H0: история каждого достаточно длинного гена BGC совместима с независимым разделением хозяев на Enterobacterales и Burkholderiales. H1: данные гена отвергают это ограничение. Отклонение H0 означает конфликт деревьев, а не автоматически HGT; неотклонение не доказывает вертикальное наследование.

## Зафиксированная выборка

- Основные листья: все 14 Pseudomonadota-носителей из `data/processed/lrcc_selected.tsv`; исключения после просмотра результата запрещены, кроме документированной ошибки идентификатора/сборки.
- Точные сборки восстанавливаются от версионного accession контига через NCBI Nucleotide→Assembly. Замена штамма молча запрещена.
- Для host tree добавляется не более одного независимого генома того же вида для каждого именованного вида-носителя: RefSeq reference, затем representative, затем наиболее полная доступная RefSeq-сборка; исходная сборка и тот же BioSample исключаются. Для записей `sp.`/`uncultured` родственник не угадывается. Это контекст устойчивости, не новая выборка BGC.
- Снимки ответов, URL, дата и SHA-256 сохраняются; недоступность сборки/родственника остаётся пропуском.

## Независимое дерево хозяев

Заранее задан список рибосомных маркеров `rplB,C,D,E,F,K,L,M,N,O,P,Q,R,S,T,V,X` и `rpsB,C,D,E,G,H,I,J,K,L,M,N,O,P,Q,R,S`. Маркер включается, если в каждой основной сборке найден ровно один CDS с таким `/gene`; дополнительным родственникам разрешён пропуск. Если полных маркеров меньше 10, допускается coverage ≥80% основных носителей, при этом каждый основной геном должен иметь ≥80% удержанных маркеров. Другие имена после просмотра дерева не добавляются.

Каждый маркер выравнивается MAFFT отдельно; сохраняются колонки с occupancy ≥80%, затем маркеры конкатенируются с partition map. ML-дерево строится IQ-TREE с выбором белковой модели и поддержкой SH-aLRT/UFBoot. Host tree используется как независимая проверка крупного таксономического разделения и для визуального контекста; слабые внутрипорядковые ветви не превращаются в ограничения.

**Поправка до выравниваний/деревьев.** Сборка *R. pickettii* DTP0602 содержит стандартные `50S ribosomal protein L#` / `30S ribosomal protein S#`, но у 29/34 выбранных CDS отсутствует `/gene`; поэтому разрешено одно заранее явное exact-product→marker соответствие без поиска похожих последовательностей. GCA_937916605.1 не содержит аннотированных CDS и исключается только из host tree как `unannotated_assembly`; соответствующий опубликованный BGC остаётся во всех четырёх gene-tree tests. H0, список маркеров и выбор BGC не изменены.

**Поправка после проверки strain metadata, не по топологии.** Автоматический same-species control GCF_060394545.1 имеет label HG29T и является новой сборкой того же HG29; он исключён из host tree как псевдореплика, но остаётся в технической проверке воспроизводимости BGC. Остальные восемь controls имеют отличающиеся strain/isolate labels; это не делает их случайной или независимой экологической выборкой.

## Деревья и формальная проверка BGC

- Формальные гены: B1, B2, C, D. A (26–40 aa) показывается только описательно.
- Для каждого гена используются все 14 последовательностей, MAFFT и удаление колонок с occupancy <80%. Ортология B1/B2/D остаётся эвристической и должна ограничивать силу вывода.
- На одном выравнивании сначала выбирается модель и строится свободное ML-дерево. Ограничение требует монофилии шести Enterobacterales и восьми Burkholderiales, но не задаёт внутрипорядковые отношения.
- Если свободное дерево уже удовлетворяет ограничению, фиксируется топологическая согласованность без искусственного второго теста. Иначе строится лучшее constrained ML-дерево с переоценкой ветвей/параметров под той же моделью, затем выполняется AU test с 10 000 RELL replicates.
- Для четырёх заранее заданных генов сообщаются raw AU p и Holm-adjusted решение при family-wise alpha 0.05. Результаты генов всё равно интерпретируются как коррелированные признаки одного локуса.

## Дополнительные признаки и альтернативы

Ранее измеренные сходства A–D, порядок генов и контекст ±20 kb объединяются только качественно. Проверяются как минимум: слабая/неустойчивая филогения, неверная ортология, дупликации/потери, рекомбинация, ошибка сборки и соседство мобильного элемента без причинной связи. HGTPhyloDetect/WAAFLE не запускаются, если этот малый case study не удовлетворяет их входной модели; название инструмента не заменяет проверку гипотезы.

Среды описываются только из доступных первичных BioSample. Направление, время, донор и межсредовой маршрут не выводятся из одного локуса.

## Правило остановки и выход

S5 заканчивается после одного host tree, четырёх заранее заданных BGC-анализов и синтеза с уже проверенным контекстом. Новая глобальная база и поиск второго положительного случая не открываются. Пакет C присваивает случаю одну из категорий: `поддерживает HGT`, `неоднозначно`, `нет достаточных свидетельств`; это не численная вероятность.
