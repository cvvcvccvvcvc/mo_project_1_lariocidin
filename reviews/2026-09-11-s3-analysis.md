# S3: аналитический отчёт по поиску в Maize Rhizosphere v1.0

## Итог

В фиксированной выборке не найдено подтверждённых контекстом lariocidin-like BGC, для которых первичные metadata поддерживают метагеномное происхождение. Три уверенных canonical BGC обнаружены в записях, помеченных MGnify как MAG, но BioSample прямо описывает их как клеточные культуры *Bacillus wiedmannii*. Они почти совпадают с опубликованным семейством: одна C-последовательность точна, вторая отличается одной заменой E93G. Это дополнительные публичные вхождения/вариант, но не новое MAG-разнообразие и не основание говорить о новом антибиотике.

Операционная H0 — выбранная MAG-выборка не добавляет подтверждённых BGC к литературному реестру — не отвергнута. H0 не «доказана»: неполнота сборок/аннотаций, 52 записи с неразрешённым происхождением и граница удалённых гомологов ограничивают отрицательный вывод.

## Что реально обследовано

| Уровень | Результат |
|---|---:|
| Записи MGnify с `Genome_type=MAG`, bacterial, completeness ≥50%, contamination <10% | 399 |
| Первичные metadata поддерживают метагеномное происхождение | 272 |
| Первичные metadata указывают cell culture | 75 |
| Происхождение не разрешено | 52 |
| Представители 100%-protein catalogue | 1 512 532 |
| CDS, напрямую восстановленные из GFF/DNA и обследованные | 1 645 120 |
| Общие последовательности, совпавшие с каталогом при проверке | 1 396 577; несовпадений 0 |
| Первичные hits при заранее заданном мягком пороге ≥80 bits | 50 белков в 42 сборках |

Название «100%-catalogue» не означает строгие полные дубликаты: MGnify v2.5.0 использует 100% identity при 80% coverage. Поэтому выполнены два поиска: по представителям каталога и напрямую по всем GFF-CDS. В GFF отсутствуют 2 183 catalogue CDS: 2 178 из них сами являются обследованными представителями; пять представлены только другим членом кластера. Эти пять — узкий остаточный пробел, а не основание объявлять весь поиск неполным.

## Контроли и курация

Итоговые HMM нашли 227/227 полноразмерных целевых C и 908/908 искусственных 50/75%-фрагментов; default HMMER и `--max` совпали. Из 4 242 белков четырёх известных геномных контекстов сработали только четыре известные C. Пять reviewed AsnB-записей (три уникальные последовательности) не прошли сито. Два other-lasso белка прошли мягкий порог, поэтому score использовался только для сбора кандидатов, а принадлежность определялась контекстом.

После сравнения последовательностей и окружения:

- **3 context-supported canonical BGC, все культуры.** У каждого C сцеплена с B1/B2, четырьмя precursor-like CDS и ABC-транспортёром. Три вхождения дают две уникальные C и два уникальных 5 267-bp core-варианта; ни один core целиком не совпал с экспортированными литературными участками.
- **37 AsnB-favoured, target unconfirmed.** Reviewed AsnB даёт больший BLAST bitscore, чем любая reference cyclase. Это сильная причина не считать их LrcC, но не экспериментальное доказательство функции.
- **10 other-lasso-affinity, target unconfirmed.** Ближайший опубликованный C относится к сравнительному Barrett-набору; целевой canonical/noncanonical контекст не подтверждён.
- **0 noncanonical hits** при заданном пороге.

## Научный смысл

1. **Главный результат S3 — ограниченный отрицательный MAG-результат плюс положительный контроль на культурах.** Он показывает, что pipeline способен найти почти известные BGC в той же коллекции, а отсутствие подтверждённых MAG-BGC не вызвано общей поломкой поиска.
2. **MGnify `Genome_type` нельзя принимать без проверки.** Если бы использовалась только таблица каталога, три культуры были бы ошибочно представлены как MAG-находки. Аудит provenance оказался частью биологического анализа, а не технической мелочью.
3. **Разнообразие не расширилось на уровне семейства, но расширилось на уровне публичных вхождений.** Один C-вариант отличается E93G, второй совпадает с опубликованным C; core DNA представлены двумя вариантами. Без поиска по всем публичным базам нельзя называть их глобально новыми.
4. **Экологический вывод узок.** Коллекция предназначена для maize rhizosphere, но включает культуры и неоднозначные записи. Допустимо сообщить происхождение трёх штаммов: root/corn, Iowa, cell culture. Нельзя считать их прямыми MAG-наблюдениями сообщества или строить межсредовой маршрут.
5. **Новый HGT-кейс из S3 не возник.** Три истинных BGC — близкие штаммы одного вида и почти опубликованные локусы; они не дают полезного cross-order конфликта. Для HGT-части рационально сохранить ранее выбранный *Photorhabdus asymbiotica*–Burkholderiales кейс и добавить ближайших родственников/независимое дерево хозяев, а не расширять поиск ради желаемой находки.

## Решение и следующий checkpoint

S3 можно считать законченным после человеческого просмотра этого отчёта. Не рекомендуется автоматически переходить к другой глобальной MAG-базе: заранее установленное правило остановки выполнено, а новый поиск превратит мини-проект в открытую программу discovery.

Следующий ограниченный этап — один HGT-разбор прежнего focal-локуса и сопоставимый вертикальный контроль. Конец проекта после него: финальная таблица разнообразия, дерево/контекст с честным выводом об определённости, воспроизводимый запуск и 3–4 слайда. Положительный HGT не является условием завершения.

## Границы достоверности

- HMM-controls зависимы от обучающего литературного набора и не дают природную sensitivity/specificity.
- Поиск охватывает аннотированные CDS и представителей catalogue-only последовательностей, но не гарантирует обнаружение пропущенных gene calls или неassembled loci.
- Общая completeness MAG не гарантирует сохранность конкретного BGC; отсутствие hit не равно биологическому отсутствию.
- Статусы 37/10 — обоснованная первичная курация, не окончательная функциональная аннотация.
- Предсказанный BGC означает генетический потенциал; производство и антибиотическая активность требуют эксперимента.
