# Данные diversity

`raw/` — неизменённые загрузки, `interim/` — временные сборки; оба каталога вне Git. `processed/` содержит восстановимые reference-файлы прежнего этапа, а `processed/discovery/` — последовательности и окружения расширенного поиска. Отдельные входы и их версии перечислены в `../inputs/`; названия файлов в `processed/` не служат подтверждением происхождения без манифеста.

Для reference-загрузки используйте `../scripts/fetch_reference.sh`; источники — `../inputs/selections/sources.tsv`, ожидаемые SHA-256 — `../inputs/provenance/checksums.sha256`. Несовпадение хеша требует проверки источника, а не замены ожидаемого значения.

Координаты в таблицах BGC — zero-based half-open внутри экспортированного BGC-record; они не обязаны совпадать с координатами полной сборки. Неверсионированный accession нельзя без проверки обновлять на текущую версию.
