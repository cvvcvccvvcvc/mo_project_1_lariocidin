# Входы и provenance

`selections/` содержит зафиксированные списки источников, выборки shards и ручные решения. `provenance/` содержит загрузочные журналы, версии, run manifests и SHA-256. `archives/` хранит крупные исходные снимки локально; они исключены из Git. Для полного повтора нужны файлы из `provenance/off_git_assets.tsv`, проверенные по `off_git_assets.sha256`.

Префикс `diversity_species_*` относится к основному видовому поиску, `diversity_extension_*` — к межсредовому расширению, `diversity_controls_*` — к контролям. Номер shard — часть зафиксированной выборки, а не порядок запуска скриптов. Старые `maize_*`, `s3_*`, `s5_*` и `reference_*` описывают прежний ограниченный этап и не заменяют текущие выборки.
