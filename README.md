# Лариоцидиноподобные BGC

Исследование разделено на два расчёта: [поиск и разнообразие BGC](diversity/README.md) и [проверку возможного HGT](hgt/README.md). Предсказанный BGC не доказывает синтез продукта; несогласие деревьев само по себе не доказывает перенос. Текущее научное состояние каждой линии описано в её каталоге, входы и версии — в манифестах рядом с кодом.

## Как повторить

1. Клонируйте репозиторий на Linux-машину с micromamba/conda и доступом к публичным источникам. Зафиксируйте commit; не смешивайте результаты разных запусков.
2. Для небольшого проверочного расчёта откройте [diversity/README.md](diversity/README.md). Для полного поиска потребуются архивы исходных метаданных, указанные в [перечне внешних входов](diversity/inputs/provenance/off_git_assets.tsv), и отдельная рабочая область. Публикация этих архивов пока не завершена: один Git clone не воспроизводит исторический полный запуск.
3. HGT использует собственные зафиксированные входы и окружение; порядок запуска и текущее состояние находятся в [hgt/README.md](hgt/README.md). Не подменяйте его входы новым diversity-каталогом без отдельной версии снимка.
4. Сравните полученные таблицы и контрольные суммы с зафиксированными манифестами. При расхождении исследуйте источник или версию, не правьте результат вручную.

## Кластер

Подключение к разрешённому login host настраивается **вне Git**: личный alias `mo-cluster` в `~/.ssh/config` (при необходимости с `ProxyJump`), приватный SSH-ключ и собственный `MO_WORKDIR` выдаются оператору кластера. Репозиторий не содержит hostname, логина, ключей или абсолютных личных путей. Типовая сессия:

```sh
ssh mo-cluster
cd "$MO_WORKDIR/lariocidin"
git pull --ff-only
cd projects/lariocidin/diversity
micromamba create -y -p .env -f environment.linux-64.lock
bash scripts/submit_baseline.sh  # после восстановления внешних архивов
squeue -u "$USER"
```

Подготовку ведите на login node, вычисления отправляйте через Slurm. Планируйте не более 64 CPU, 512 GiB RAM и 250 GB диска суммарно; актуальные partition, QOS и квоту проверяйте у администратора. Большие геномы, архивы, окружения, журналы и презентация остаются вне Git. Их происхождение и SHA-256 должны быть указаны в манифестах; приватные настройки никогда не копируйте в репозиторий.
